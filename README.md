# Prime & NorthLab Radar

Unified lead-intelligence infrastructure for **Prime Kıbrıs** and **NorthLab**.

## Active radars

- **Prime Buyer Radar** — North Cyprus property purchase demand
- **NorthLab Sales Radar** — website, software, automation and digital-project demand
- **Prime Competitor Radar** — market/competitor monitoring
- **Telegram inventory searches** — targeted property availability scans

## Core infrastructure

- Telegram joined groups/channels
- Public web and forum sources
- Russian public sources
- Firestore deduplication/state
- Telegram notifications

## Required secrets

- `FIREBASE_SERVICE_ACCOUNT_JSON`
- `FIRESTORE_COLLECTION` (optional)
- `FIRESTORE_SCAN_COLLECTION` (optional)
- `TELEGRAM_BOT_TOKEN` (optional)
- `TELEGRAM_CHAT_ID` (optional)
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_STRING_SESSION_PRIME`

> This repository no longer represents the legacy BAY-S project. It is the shared radar infrastructure for Prime Kıbrıs and NorthLab.
